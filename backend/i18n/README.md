# Uchqun i18n Translations

## ⚠️ AI-Generated — Unverified

The translation files in this directory (`ru.json`, `uz-latn.json`, `uz-cyrl.json`)
were generated by an AI language model (Claude claude-sonnet-4-6) and have **not been
reviewed or corrected by a native speaker**.

These files are shipped with the platform for completeness, but they may contain:
- Grammatical errors
- Awkward phrasing
- Register mismatches (formality conventions)
- Outright translation mistakes

### Why this approach

A professional human translator was not engaged for this version of the platform
due to resource constraints. The platform owner has made this trade-off explicitly:
AI-generated translations now, professional review before real-user launch.

### Before real-user launch

Before this platform serves real parents, teachers, or schools at scale, a native
Russian speaker and a native Uzbek speaker (with proficiency in both Latin and
Cyrillic scripts) should review and correct each translation. This is tracked in
the pre-launch checklist as PL-009-VERIFY.

### Review priority

The `_metadata._review_priority` array in each file lists codes that should be
reviewed first. These are safeguarding-related strings (account suspension, school
archival, access restriction) where mistranslation could cause confusion or alarm.

### How to update

Edit the JSON files directly. Each is a flat map of `ERROR_CODE` → translated string.
Update the `_metadata` block's `verification_status` to `VERIFIED` and add the
reviewer's name and date when professional review is complete.

### Code list

See `audits/backend/i18n-error-codes.md` for the authoritative list of all 106 error
codes with English reference text and frontend usage guidance.

### Validation

Run `node backend/scripts/verify-i18n.js` from the project root to verify that all
106 catalog codes have entries in every language file and that no extra keys exist.
This script is also used in CI to catch drift between the catalog and language files.
